# OnIt — Автоматизация браузера по расписанию (FastAPI + SQLAlchemy + Selenium + PostgreSQL)

Сервис для выполнения инструкций в браузере через **Selenium** по расписанию (регулярному и разовому) с управлением через **Swagger UI** (`FastAPI`) и хранением данных в **PostgreSQL** (`SQLAlchemy`).

---

## Возможности

1. **Инструкции (`instruction`)**:
   - `url` — ссылка, которую открывает Selenium.
   - `cookie` — куки в формате JSON `{ "ключ": "значение" }` (опционально). При наличии куки добавляются в браузер, после чего страница автоматически обновляется (`driver.refresh()`).
   - `steps` — шаги в формате JSON `{ "ключ_элемента": "действие" }`:
     - **Поиск элемента (`ключ`)**: программа последовательно проверяет стратегии поиска в порядке:
       `[текст, id, name, тэг, class, xpath]` и выбирает **первое совпадение**.
     - **Действие (`значение`)**:
       - `"click"` — клик по найденному элементу;
       - любая другая строка (или `"input:текст"` / `"send_keys:текст"`) — ввод текста (`send_keys`) в найденный элемент;
       - также поддерживаются `"clear"`, `"submit"`, `"enter"`, `"double_click"`, `"hover"`, `"wait:N"`.

2. **Регулярное расписание (`regular_action`)**:
   - Привязывается к инструкции (`instr_id`), дню недели (`day`: `0` = Понедельник … `6` = Воскресенье) и интервалу времени (`time_start`, `time_end`).
   - При совпадении системного дня недели и времени с интервалом `[time_start, time_end]` запускается браузер, выполняет шаги и **удерживает вкладку открытой до `time_end`**, после чего закрывает браузер.

3. **Нерегулярное (разовое) расписание (`single_action`)**:
   - Привязывается к инструкции (`instr_id`), конкретной дате (`date`), интервалу времени (`time_start`, `time_end`) и флагу `is_complete`.
   - При совпадении даты и времени запускается браузер, выполняет шаги, удерживает браузер открытым до `time_end` и отмечает `is_complete = true`.

4. **Логи выполнения (`log`)**:
   - Результаты каждого запуска (успех/ошибка, дата, время, подробное описание выполненных шагов) сохраняются в таблицу `log`.

## Настройка и запуск

### 1. Переменные окружения (`.env`)
```env
DATABASE_URL=postgresql+psycopg2://postgres:admin@localhost:5432/postgres
# Опционально:
# SELENIUM_HEADLESS=false
# SELENIUM_STEP_TIMEOUT=15
# SCHEDULER_INTERVAL_SECONDS=10
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Запуск сервера FastAPI
```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```
Таблицы в PostgreSQL создаются автоматически при старте приложения (также можно запустить `python database/create_db.py`).

### 4. Swagger UI
Откройте в браузере:
- `http://localhost:8000/docs` (или просто `http://localhost:8000/`)
